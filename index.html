Описание для выбранной системы


Перед переносом исходная Jira перечитывается. Совпадение определяется по последним пяти цифрам в конце названия, например [21783]. Найденная задача обновляется вместе с названием; различия в тексте названия не приводят к созданию новой задачи.





Нужно проверить систему назначения


Отправка уже началась, но подтверждение создания не получено. Проверьте список задач выбранной системы. Повторная отправка может создать дубликат. Для локальной Jira найденная задача будет использована для продолжения загрузки файлов.

Не сохранены страницы
    Перенос продолжается без этих MHTML-архивов. Остальные файлы прикладываются к задаче.
    

    

    После ошибки снимает блокировку и позволяет начать другую задачу. Во время выполняющегося переноса кнопка недоступна. Уже созданные задачи и загруженные файлы сохраняются.
    

    

    Вкладку утилиты можно закрыть: перенос продолжится в фоне. Вкладки сайтов нужны для входа и сохранения MHTML. Исходная Jira не изменяется.
